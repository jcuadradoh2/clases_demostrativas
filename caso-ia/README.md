# Caso práctico IA Solutions Engineer — visor de la presentación

Sitio estático para GitHub Pages.

| Archivo | Para qué sirve |
| --- | --- |
| `index.html` | Visor de la presentación: flechas del teclado para avanzar, tecla F para pantalla completa (Esc vuelve), lápiz en pantalla completa, texto de cada lámina y miniaturas. |
| `slides/` | Láminas exportadas como imagen JPG de 1920 × 1080 (`lamina-1.jpg` … `lamina-21.jpg`). |
| `Presentacion_Caso_Practico_IA.pdf` | Presentación en PDF, sin notas del orador. |

Si cambia la presentación, exporte de nuevo cada lámina como `slides/lamina-N.jpg` y actualice la lista `LAMINAS` de `index.html` si cambia el número de láminas.
